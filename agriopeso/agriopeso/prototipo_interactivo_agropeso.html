Documentación de Heurísticas de Jakob Nielsen Aplicadas

Justificación técnica de los principios aplicados en las pantallas de AGROPESO.

1

Visibilidad del estado del sistema

Aplicación específica: En la pantalla de Registro de Pesaje, el panel lateral derecho actualiza instantáneamente la tara, el peso neto y el subtotal monetario cada vez que el operador modifica el peso bruto o el número de arpillas. Además, el indicador superior muestra en todo momento el estado de sincronización offline (estado_sincronizacion), informando cuántos registros esperan conexión con el servidor central.

2

Prevención de errores

Aplicación específica: El sistema bloquea automáticamente el botón de Registrar Pesaje y despliega una alerta visual clara si el operador selecciona un jornalero con estatus "Bloqueado" o si el peso neto resultante de restar las arpillas es menor o igual a 0.00 kg, evitando registros inválidos en la base de datos.

3

Consistencia y estándares

Aplicación específica: Todas las vistas mantienen una estructura uniforme: barra superior institucional, ruta de navegación, tarjetas agrupadas por flujo lógico y botones de acción ubicados consistentemente en la esquina inferior derecha con códigos de color estándar (verde para confirmar, gris para cancelar).

4

Coincidencia entre el sistema y el mundo real

Aplicación específica: Se utiliza terminología propia del campo agrícola regional (arpillas, cuadrilla, jornalero, tara, chile verde/seco) en lugar de tecnicismos informáticos, facilitando la adopción inmediata por parte de los operadores de báscula sin requerir capacitación compleja.
